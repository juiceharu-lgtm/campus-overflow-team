## 1. 核对口径

本清单区分三类来源，不能互相替代：

- **课程明确要求**：`CampusOverflow实验部分 (1).pdf` 的 Lab1～Lab8。下文页码采用 PDF 文件页序，并同时标注正文印刷页码。
- **仓库 README 要求**：初始框架自检、TODO 实施顺序和仓库验收门槛。
- **团队自行安排**：A/B/C 分工、阶段记录、前端增强、最终证据目录和内部协作任务。

状态含义：

- **配置已存在**：仓库有源码或配置文件，不代表已运行、部署或验收成功。
- **实际运行通过**：有真实命令、环境、输出和提交版本可追溯。
- **已提交待评审**：存在未合并 PR，不代表成果已进入 main。
- **待负责人确认**：当前缺少可引用证据，不能据此认定尚未开发。
- **尚待完成**：已有证据可以确认该验收尚未执行或尚未通过。

远端状态已于本次提交前通过 GitHub 页面核对：最新 main 仍为 `6697eed`；PR #2、#3、#5 为开放正式 PR，PR #4 为开放 Draft，均未合并且均显示 2/3 checks passing。
