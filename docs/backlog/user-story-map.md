# 用户故事地图 CampusOverflow
> Lab2 Sprint1，A角色主执笔，全员参与讨论
整体用户主线：未注册用户 → 注册 → 浏览内容 → 提问 → 回答问题 → 互动投票采纳 → 成长获取声誉

## 顶层用户活动（横轴）
1. 用户账号注册与身份管理
2. 浏览平台问答内容
3. 发布提问
4. 回答问题
5. 问答互动（投票、采纳答案、打标签）
6. 用户成长与声誉获取

## 纵轴：业务故事卡片（MVP优先的故事在上方）
### 1. 用户账号注册与身份管理
- 作为访客，我可以注册平台账号，以便登录系统
- 作为登录用户，我可以维护个人资料，以便展示个人信息
- 作为教师角色，我可以审批学生选课申请，完成身份扩展（Identity增量）

### 2. 浏览平台问答内容
- 作为访客，我可以浏览问题列表，快速查看公开问答
- 作为访客，我可以查看问题详情，阅读问题与全部回答

### 3. 发布提问【Sprint1 MVP核心】
- 作为登录用户，我可以发布新问题，描述我的疑惑
- 作为登录用户，我可以编辑自己发布的问题
- 作为登录用户，我可以给自己的问题打上标签，便于归类检索

### 4. 回答问题【Sprint1 MVP核心】
- 作为登录用户，我可以对已有问题提交回答
- 作为登录用户，我可以编辑我自己提交的回答

### 5. 问答互动（投票、采纳答案、打标签）【Sprint3】
- 作为登录用户，我可以对回答进行点赞/点踩投票
- 作为提问者，我可以采纳满意的回答作为正确答案
- 作为用户，我可以给问题增加标签，方便归类

### 6. 用户成长与声誉获取【Sprint3】
- 作为用户，我完成提问、回答、被采纳，自动获得声誉分值
- 作为用户，我可以查看自己的声誉分数，了解平台贡献

## Walking Skeleton（Sprint1 MVP骨架切片）
> Sprint1只实现：注册登录、浏览问题列表、查看详情、发布提问、提交回答；
> 投票、采纳、声誉放到Sprint3实现。
