# 聚合清单与业务不变式
## 聚合识别清单（紫色聚合卡片）
| 聚合根实体 | 归属限界上下文 | 关键业务不变式 |
| ---- | ---- | ---- |
| UserAccount | Identity | 用户账号唯一；邮箱不可重复注册；仅本人可修改个人资料；教师才拥有选课审批权限 |
| Question | Q&A | 问题标题、正文不能为空；仅提问者可以编辑问题；问题删除后关联回答一并失效 |
| Answer | Q&A | 回答必须绑定有效存在的Question；仅回答作者可编辑回答；一个问题可以拥有多条回答 |
| UserReputation | Reputation | 声誉分数≥0；分数只能由系统业务行为自动计算，用户无法直接手动修改分数 |
| QuestionIndex | Discovery | 索引数据必须和Q&A上下文的问题数据保持最终一致性 |
