# 事件风暴 Event Storming
Lab3 Sprint1｜A角色主执笔，全员参与研讨
> 本文件为团队数字白板整理输出，基于全员头脑风暴结果；
> 包含：参与者、领域事件、命令、聚合、不变式、限界上下文、上下文映射、统一语言术语表。

## 参与角色（黄色卡片）
访客、注册普通用户、提问者、回答者、教师、系统定时任务

## 系统限界上下文划分
1. **Identity 身份上下文**：账号注册、个人资料、选课审批、身份权限管理
2. **Q&A 问答上下文**：问题发布、编辑、回答提交、投票、答案采纳，平台核心问答业务
3. **Reputation 声誉上下文**：根据用户问答行为自动计算、维护用户声誉分值
4. **Discovery 发现上下文**：标签、检索、问题索引，实现内容查找过滤

## 事件‑命令卡片集合
### Identity 身份上下文
- 命令：访客提交注册申请
- 领域事件：【用户账号已注册】
- 命令：登录用户更新个人资料
- 领域事件：【用户个人资料已更新】
- 命令：教师提交选课审批操作
- 领域事件：【选课申请审批通过】
- 领域事件：【选课申请审批驳回】

### Q&A 问答上下文
- 命令：登录用户发布新问题
- 领域事件：【新问题已发布】
- 命令：提问者编辑自己的问题
- 领域事件：【问题内容已更新】
- 命令：登录用户提交回答
- 领域事件：【回答已提交】
- 命令：回答者编辑已有回答
- 领域事件：【回答内容已修改】
- 命令：提问者采纳某一条回答
- 领域事件：【回答被采纳为正确答案】
- 命令：用户对回答执行投票（点赞/点踩）
- 领域事件：【回答投票状态发生变更】

### Reputation 声誉上下文
> 由其他上下文的领域事件触发，系统自动执行，用户不能直接修改分数
- 命令：系统执行声誉分值更新
- 领域事件：【用户声誉分值发生变更】

### Discovery 发现上下文
- 命令：用户按标签/关键词检索问题
- 领域事件：【问答检索结果返回】
- 命令：问题发生变更，更新检索索引
- 领域事件：【问答索引数据已同步更新】
